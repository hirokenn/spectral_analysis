# spectral_analysis

## プロジェクト概要

木材の近赤外（NIR）スペクトルから含水率を予測する回帰タスクを扱うプロジェクトです。  
ケモメトリクス的アプローチと機械学習アプローチを比較しながら、スペクトルデータの前処理・学習・評価を進めることを目的としています。

## データ情報ドキュメント

データセットの基本情報（サイズ、カラム定義、統計量）と、解析に必要な事前知識は以下にまとまっています。

- `docs/data_info.md`
- `docs/domain_knowledge.md`

## このコンペで難しい点・注意点

- `train.csv` と `test.csv` で出現する樹種が非重複であり、未知樹種への汎化性能が重要です。
- 特徴量は 1,555 次元の高次元スペクトルで、サンプル数（train: 1,322）に対して過学習しやすい設定です。
- 含水率は分布の裾が長く（高値側の外れがある）、RMSE 評価では高含水率サンプルの誤差が効きやすいです。
- 近赤外スペクトルは散乱・ベースライン変動・測定条件の影響を受けやすく、前処理（SNV、微分、平滑化など）が性能に直結します。
- 検証はランダム分割だけに頼らず、樹種単位の分割（GroupKFold / Leave-One-Species-Out）での確認が推奨されます。

## 環境構築

### 前提

- Python 3.12 以上
- `uv` がインストール済みであること

### セットアップ手順

1. 仮想環境を作成

```bash
uv venv
```

2. 仮想環境を有効化

```bash
source .venv/bin/activate
```

3. 依存関係をインストール

```bash
uv sync --all-groups
```

4. コマンド実行確認（任意）

```bash
uv run python --version
```

### 品質チェックコマンド

```bash
uv run mypy src
uv run black .
uv run ruff check src
uv run pytest
```
