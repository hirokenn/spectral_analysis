# 本コンペに関連するドメイン知識と事前知識

木材の近赤外（NIR）スペクトルから含水率を予測するうえで、最低限押さえておきたい背景知識を整理したドキュメントです。  
「なぜこの前処理やモデルが効くのか」を判断するための観点をまとめています。

## 1. 課題の本質

- 入力: 木材表面の近赤外スペクトル（10000〜4000 cm⁻1）
- 出力: 含水率（%）
- 評価指標: RMSE（小さいほど良い）

この課題は、単純な回帰問題に見えて、実際には以下の要素が混在します。

- 化学情報: 水や木材成分由来の吸収
- 物理情報: 散乱、表面状態、繊維方向、密度差
- 測定系の影響: プローブ距離、光学系、器差

そのため、スペクトル処理と検証設計の良し悪しが精度に直結します。

## 2. 近赤外スペクトルの基礎

### 2.1 何を測っているか

近赤外は主に分子振動の倍音・結合音を観測します。  
中赤外のような鋭いピークではなく、広く重なった吸収帯になりやすい点が特徴です。

### 2.2 波数と情報

- 本データの軸は波数（cm⁻1）
- 高波数側から低波数側へ並んでいる
- 近赤外では水に由来する吸収が特に強く、含水率予測に重要

代表的には O-H に関係する帯域（例: 約7000 cm⁻1 付近、約5200 cm⁻1 付近）が水分情報に寄与しやすい一方、実際の寄与は散乱や他成分との重なりで変化します。

### 2.3 木材試料特有の難しさ

- 異方性: 板目・柾目・追い柾で光の散乱挙動が変わる
- 密度差: 光路長や散乱強度に影響
- 乾燥収縮: 測定中にプローブ-試料距離が変わる可能性
- 表面状態: 粗さや局所構造が反射強度を変える

これらは「化学濃度が同じでもスペクトル形状が変わる」原因になります。

## 3. ケモメトリクスの考え方

ケモメトリクスでは、以下を重視します。

- 高次元・多重共線性のあるスペクトルを安定に扱う
- 前処理で不要変動（散乱・ベースライン）を抑える
- 少数サンプルでも過学習しにくいモデルを選ぶ
- 予測精度だけでなく解釈可能性も見る

特に本課題では、未知樹種への外挿に近い状況があるため、「学習データ内での当てはまり」より「汎化性」の重みが大きいです。

## 4. 代表的な前処理手法

前処理は単独よりも、目的に沿った組み合わせで使うことが多いです。

### 4.1 散乱補正

- SNV（Standard Normal Variate）  
  各サンプルスペクトルを平均0・分散1に正規化し、乗法散乱・オフセットの影響を軽減
- MSC（Multiplicative Scatter Correction）  
  参照スペクトルへの回帰でスケール差とオフセット差を補正

### 4.2 ベースライン補正・正規化

- detrend（トレンド除去）
- ベースライン補正
- ベクトル正規化・面積正規化

### 4.3 平滑化と微分

- Savitzky-Golay 平滑化
- 1次微分: ベースラインの影響低減、ピーク変化の強調
- 2次微分: 重なりピーク分離に有効だがノイズ増幅に注意

微分を使う場合は、窓幅・多項式次数の探索が重要です。

## 5. 回帰モデルの代表例

### 5.1 線形系（まずの基準）

- PLS回帰（PLSR）  
  スペクトル回帰の定番。潜在変数数の調整が性能を左右
- PCR  
  主成分を介した回帰。PLSより目的変数との結びつきが弱い場合あり
- Ridge / Lasso / Elastic Net  
  高次元線形回帰の安定化に有効

### 5.2 非線形系

- SVR（RBF など）  
  中規模データで有効なことが多い
- 木系アンサンブル（Random Forest, Gradient Boosting 系）  
  そのままのスペクトルでは次元が高く、前処理や次元削減と併用が前提

非線形モデルは表現力が高い反面、樹種リークや分割設計の不備があると過大評価されやすい点に注意が必要です。

## 6. 検証設計で注意すべき点

本コンペでは、`train.csv` と `test.csv` で樹種が非重複です。  
そのためランダム分割のCVだけだと、実運用より楽な条件で評価してしまう可能性があります。

推奨観点:

- GroupKFold（group=species）で樹種単位の分割
- Leave-One-Species-Out で未知樹種への頑健性確認
- 前処理・特徴選択・ハイパーパラメータ探索は必ずCVの内側で実行

データリークを避けるため、`Pipeline` で前処理とモデルを一体化して評価するのが安全です。
