# train.csv データ基本情報

`data/train.csv` を解析し、サイズ・カラム定義・単純統計量をまとめたドキュメントです。

## 1. データサイズ

- ファイル: `data/train.csv`
- 文字コード: CP932（Shift_JIS系）
- 行数: 1,322（ヘッダー除く）
- 列数: 1,559
  - メタ情報列: 4
  - スペクトル列: 1,555
- 欠損値: 0（全列で欠損なし）

## 2. カラム定義と中身

### 2.1 メタ情報列（先頭4列）

| カラム名 | 型 | 中身（意味） | 値の例 | 備考 |
|---|---|---|---|---|
| `sample number` | 数値（実質ID） | 各測定レコードのサンプル番号 | `1`, `1872` | 1〜1872の範囲。重複なし（1322件ユニーク） |
| `species number` | 数値（カテゴリID） | 樹種ID | `1`, `14`, `19` | 本データでは13種類のIDが出現 |
| `樹種` | 文字列 | 樹種名（日本語） | `イチョウ`, `ヒノキ` | `species number` と1対1対応 |
| `含水率` | 数値 | 目的変数（予測対象） | `216.1290323` | 単位は課題説明どおり `%` |

### 2.2 スペクトル列（5列目以降）

- カラム名自体が波数（cm⁻¹）を表す数値文字列
  - 先頭: `9993.76781`
  - 末尾: `3999.82139`
  - 列数: 1,555
- 並び順は高波数→低波数（単調減少）
- 列間隔はほぼ一定（約 `3.857108 cm⁻¹`）
- 各セルの値は、その波数でのスペクトル値（吸光度）
